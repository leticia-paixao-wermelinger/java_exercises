💻 Challenge: Modeling and Managing Computer Data Using Java Classes and Encapsulation
Create a Java application that models computers using object-oriented programming principles.
The system must include a class named Computer with attributes such as brand, model, year,
serial number, and processor. Focus on implementing proper encapsulation, including getter
and setter methods, and input validation to ensure data integrity.

The class should feature two constructors: a default one that requests user input via the console,
and a parameterized one that initializes all attributes directly. Include a method to print the full
computer information in a structured format.

To demonstrate and test the class behavior, implement an application class named ComputerStore.
In it, instantiate four Computer objects—two using the default constructor and two using the
parameterized one. Display the data for all instances and validate edge cases, such as invalid input
values or empty fields.

💡 Suggestions and Extensions
Consider implementing data validation rules such as checking for string length limits, allowed
characters, and valid year ranges. You can also explore ways to improve user interaction through
input feedback loops and error handling. As a next step, the system could be expanded with features
like storing multiple computers in a list or file, or filtering and searching based on specific attributes.

Optionally, you may include a class diagram to visually represent the structure of the application,
emphasizing encapsulation and constructor overloading.
